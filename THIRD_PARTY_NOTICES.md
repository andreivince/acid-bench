The bundle adds three publication-local commits to the official upstream commit
`59a200c6d575d595120f1cb70fea53cef0632f6b`; together with the patch they wire in
the ACID proxy, the scripted user, run metadata and tool-call diagnostics. One
change alters environment behavior: in the airline tool
`update_reservation_flights`, the patch also writes the requested cabin to the
reservation (`reservation["cabin"] = cabin`), which upstream Tau-Bench does not
do. Results here are for the patched environment.

The scenario contracts and trace samples contain records from Tau-Bench's
synthetic retail and airline databases (names, addresses, `example.com` email
addresses, orders and reservations). These are fixture data, not real people.

## Model outputs in the traces

The agent turns in `artifacts/trace-audit/samples/` and in the compact trace
dataset were generated by these models, each identified per run by the `model`,
`model_owner` and `provider` fields:

| Model | Owner | Served by |
| --- | --- | --- |
| DeepSeek V4 Flash (non-thinking and thinking-max) | DeepSeek | DeepSeek API |
| DeepSeek V4 Pro (thinking-max) | DeepSeek | DeepSeek API |
| MiniMax M2.7 (reasoning-low) | MiniMax | OpenRouter |
| Kimi K2.6 (reasoning-high) | Moonshot AI | OpenRouter |

These outputs are AI-generated. They are subject to each model provider's terms
in addition to the data license of this repository. The user turns come from a
local scripted user, not from a hosted model.
